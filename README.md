# deutschwithayan

**Deutsch with Ayan** (German: *Deutsch mit Ayan*, Arabic: *ألماني مع أيان 🇩🇪 🇪🇬*) — An intuitive, modern German learning application built with React Native and Expo SDK 57.

## 🌟 Highlights
- **Full CEFR Levels (A1 - C2)**: Comprehensive grammar, official test diagnostics, and interactive audio lessons.
- **Collins 3,000 Words & Phrases**: Over 3,200 curated entries categorized by CEFR level with real-life context examples, grammar tips, and Egyptian Arabic translations.
- **Trilingual Reading & Pronunciation (🇩🇪 🇬🇧 🇪🇬)**: Instant audio pronunciation for German, English, and Egyptian Arabic with zero voice overlap.
- **Interactive Mini-Games**: Memory Spiel (Pairs Match), Article Sorter Blitz, Kids Adventure, Sentence Builder, and Verb Race.
- **Dark & Light Mode**: Dynamic claymorphic theme with crisp contrast and full RTL support.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- Expo CLI

### Installation
```bash
npm install
```

### Running Locally
```bash
npm start
```
Scan the QR code with **Expo Go** on Android or the **Camera** app on iOS.

### Running Tests
```bash
npm test
```
